# Музыка по станциям

Положи mp3-файлы сюда с такими именами — сайт сам их подхватит (иначе просто играет без звука):

- `warmup.mp3`
- `court.mp3`
- `memory.mp3`
- `neuroset.mp3`
- `puzzle.mp3`
- `summary.mp3`

Ничего менять в коде не нужно — станция сама проверяет, есть ли файл, и показывает кнопку 🔊/🔇 только если он на месте.
